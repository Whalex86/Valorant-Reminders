What it does

One notification, timed to the game — not the clock

Break and hydration reminders that fire on a fixed timer land wherever they land — sometimes in the middle of a clutch round. This tool instead waits for Valorant to report that the match itself has ended, then shows a single desktop notification with a message the player has written themselves — "drink some water," "stretch," or anything else.

  • Fires once per match, on the official match outcome (victory / defeat / draw)
  • Message text is fully user-configurable, separately for each outcome
  • No effect on gameplay, input, or the game client in any way

How it works

Built on Overwolf's official event feed

The app runs as an Overwolf application and subscribes to Overwolf's Game Events Provider (GEP) for Valorant — the same officially supported integration Overwolf exposes for other approved apps. It reads the match_info feature's match_outcome field once a match concludes, and the game_info feature to know when Valorant has launched or closed.

It does not read game memory, hook the game process, automate input, or access any data beyond what Overwolf's sanctioned GEP feed already provides.

Setup

Getting it running

  1. Install Overwolf and enable developer mode, if not already set up.
  2. Load the app as an unpacked Overwolf extension from its project folder.
  3. Open the app from the Overwolf dock and set your own win / loss / draw messages.
  4. Launch Valorant — the app runs quietly in the background and notifies you once each match ends.

Privacy policy

What data this app touches

This app is for personal, single-user use and does not have a backend server, account system, or analytics.

Data read

Match outcome data (victory / defeat / draw) and game running-state, provided locally by Overwolf's Game Events Provider while Valorant is running.

Data stored

Only the user's own custom reminder messages and an on/off toggle, saved locally on the user's machine. Nothing is transmitted anywhere or shared with any third party.

Data shared

None. This app makes no network requests and has no server component.
